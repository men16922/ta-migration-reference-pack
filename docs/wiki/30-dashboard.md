> **요약**: 최근 동기화 정보를 머리에 두고, KPI 타일 4개(자산·업무 시스템·WEB/WAS/DB·최근 변경), 업무별 자산 표, 센터별 자산 분포를 보여준다. 모든 타일은 해당 상세 화면으로 이동한다.

> **관련 페이지**: [20](20-api-contract.md#2-summary-목표-형태), [31](31-diagram-engine.md), [33](33-ui-pages-and-menu.md)

## 화면 구성 (현재 그대로 이식)

```text
┌ 페이지 머리 ───────────────────────────────────────────────────────────┐
│ 대시보드                                            [IDC 구성도 열기 →] │
│ 최근 Excel 등록 #6 · servers.xlsx / Sheet · 2026.10.22 09:00           │
└───────────────────────────────────────────────────────────────────────┘
┌ 자산 ─────┐ ┌ 업무 시스템 ┐ ┌ WEB · WAS · DB ┐ ┌ 최근 변경 ─────────────┐
│ 7         │ │ 1           │ │ 3              │ │ 1                      │
│ 최근 등록 │ │ [미분류 4]  │ │ 서버 연결      │ │ [추가 0][삭제 0][변경 1]│
│ 자산 기준 │ │  또는 [전체 │ │ 미확인 0건     │ │                        │
│           │ │  분류됨]    │ │                │ │                        │
└───────────┘ └─────────────┘ └────────────────┘ └────────────────────────┘
┌ 업무별 자산 (10/16 폭) ─────────────────────┐ ┌ 센터별 자산 (6/16) ─────┐
│ 업무 시스템 | 자산 | 환경   (상위 6개)       │ │ 시험센터 ████ 7대 100% │
│ 합성 ERP    |  3   | 운영                    │ │ (상위 6개, 진행 막대)  │
└─────────────────────────────────────────────┘ └────────────────────────┘
```

| 요소 | 데이터 | 클릭 시 |
|---|---|---|
| 머리 부제 | `summary.run`: id, source_name, sheet, finished_at → TO-BE `last_batch` | — |
| `IDC 구성도 열기` 버튼 | — | IDC 구성도 |
| KPI 자산 | `assets.total` | 자산 목록 |
| KPI 업무 시스템 | `projects`; `assets.unclassified > 0`이면 빨간 태그 `미분류 자산 N`, 아니면 초록 `전체 분류됨` | 업무 시스템 목록 |
| KPI WEB·WAS·DB | `components.total`; 보조 `서버 연결 미확인 {components.unmatched}건` | WEB·WAS·DB 목록 |
| KPI 최근 변경 | `last_diff.added + removed + changed`; 태그 추가(초록)/삭제(빨강)/변경(파랑). 이전 이력 없으면 `-`와 `비교할 이전 등록 이력이 없습니다.` | 변경 이력 |
| 업무별 자산 표 | `GET projects?page_size=6`: 업무 시스템(굵게), 자산, 환경(`·` 구분). 설명 `전체 N개 업무 시스템 · 항목을 선택하면 구성도를 엽니다.` | 행 → 업무 시스템 상세 |
| 센터별 자산 | `summary.sites` 상위 6개. 막대 값 = 대수, 보조 `N대 · P%` (P = 대수/자산 전체) | — |

그리드: Carbon 16열 기준 KPI는 `lg=4`씩, 표 `lg=10`, 분포 `lg=6`; 중간 폭(`md=8` 기준) KPI `md=4`, 표·분포 `md=8`; 모바일(`sm=4`) 모두 한 줄. 호스트 그리드 체계로 같은 비율을 맞춘다.

## 빈 상태

자산이 하나도 없으면(`workspace.has_assets=false`) 대시보드 대신 안내 타일을 보여준다: 제목 `등록된 자산이 없습니다`, 설명 `ESM에서 내려받은 서버·장비 Excel을 등록하면 자산 목록과 구성도를 확인할 수 있습니다.`, 버튼 `첫 Excel 등록`(업로드 화면). 근거: `src/App.tsx`.

## 값의 정의

| 값 | 정의 (현재 코드) |
|---|---|
| 자산 total | 현재 활성 자산(servers+equipment+security) 수. 인스턴스 미포함 |
| servers | `review.is_server`: `category`/`category_detail`에 네트워크·보안·스토리지·NAS·SAN·백업·테이프·`미분류 장비` 패턴이 없으면 서버 |
| unclassified | `project`가 없는 자산 수(장비 포함 — 네트워크 공통 장비가 미분류로 잡힐 수 있음, [43](43-known-gaps-and-pitfalls.md)) |
| projects | 공통(`shared`) 아닌 업무 코드 수 + 인스턴스에만 있는 업무 코드 |
| components.unmatched | `match_status != matched` 인스턴스 수 |
| last_diff | 직전 실행 대비 자산 + 인스턴스 합산 추가/삭제/변경 → TO-BE 마지막 변경 배치의 `idc_change` 집계 |

## 제안 위젯 (선택, 기본 미구현)

사용자가 "온프렘 IDC 대시보드 및 시각화"를 원하므로 아래를 2차 후보로 둔다. 모두 현재 데이터로 계산 가능하고 추정이 없다.

| 위젯 | 데이터 | 비고 |
|---|---|---|
| 장비 종류 분포 | `device_kind`별 수(방화벽·보안장비·L4·스위치·SAN·스토리지·백업·기타) | 구성도 범례와 같은 라벨 |
| 그룹사 × 센터 표 | (organization, site)별 서버/장비/인스턴스 수 | 구성도의 센터 상자와 1:1 |
| OS 분포 | `os_family`/`os`별 서버 수 | EOS 판정은 하지 않음(제외 범위) |
| 데이터 품질 | 미분류 자산, 서버 연결 미확인 인스턴스, IP 없음 자산, 마지막 배치 경고 수 | 각 항목 → 필터된 목록 |
| 동기화 추이 | 최근 N개 배치의 추가/변경/삭제 막대 | `recent_batches` |

차트는 호스트 차트 라이브러리를 쓴다. 색은 구성도와 맞춰 흑백·회색 계열을 기본으로 한다.
