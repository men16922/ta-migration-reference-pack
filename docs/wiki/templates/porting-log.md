# 포팅 작업 기록 (양식)

> 단계마다 하나씩 위에 추가한다(최신이 위). 회사 저장소 안에 둔다.

```markdown
## YYYY-MM-DD — P<n> <단계 이름>

- 상태: 완료 | 진행 중 | 막힘
- 읽은 위키: 12, 13, …
- 계획: <바꿀 파일과 이유 3~5줄>
- 변경: <파일 목록>
- 테스트: <통과한 ID 목록> / 실패: <ID와 원인>
- 결정: D-xx 기본값 적용 / D-yy 회사 답변 반영(<내용>)
- 원본과 다른 점: <의도적으로 다르게 구현한 동작과 이유>
- 남은 문제·질문: <…>
- 다음: <다음 단계 첫 작업>
```
