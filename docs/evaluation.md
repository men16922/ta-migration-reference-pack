# 기능·사용성 평가 — 2026-10-22

**로컬에서 ESM Excel을 등록하고 자산·업무별 구성도를 관리하는 용도로는 사용할 수 있다. 회사 공용 서비스로 배포할 준비는 아직 완료되지 않았다.** 실제 회사 Excel 인수, 인증·권한, Agent 연결이 남아 있다. 이 평가는 합성 데이터와 로컬 Chrome에 근거하며 사용자 인터뷰나 사내 실운영 평가를 대신하지 않는다.

## 사용성 평가

메뉴를 등록 → 자산/인스턴스 → IDC/업무 구성도 → 변경 이력으로 정리했다. 불필요한 네트워크 학습·이관 준비도 화면을 제거했다. 업무 목록은 자산 대수와 인스턴스 수를 따로 보여주고, 업무 상세에서 해당 구성도 편집으로 이동할 수 있다.

Chrome의 기본 폭 약 864px, 데스크톱 1440×1000, 좁은 화면 640×900에서 주요 동작을 확인했다. 좁은 화면에서 메뉴 열기 후에도 내비게이션이 숨겨지는 CSS 문제를 재현·수정하고 페이지 이동을 다시 확인했다. draw.io는 데스크톱에서 양쪽 도구와 캔버스를 함께 쓰는 편이 적합하다. 좁은 화면의 정밀 편집·모든 모바일 브라우저·전체 키보드/스크린리더 사용성은 인수 검증하지 않았다.

저장 요청 중 새 편집이 들어오면 미저장 표시가 사라지는 문제를 실패 테스트로 재현한 뒤 수정했다. 추가 편집은 다음 저장까지 미저장 상태를 유지한다. 과거 이력을 불러오면 최신 버전 번호 대신 실제 불러온 버전 번호를 표시한다. 외부 origin의 편집기 메시지는 무시한다.

개선이 남은 부분:

- 반복 파일의 무변경 업로드는 자동 생략하지 않아 이력·파일이 늘어난다. 보관 정책과 무변경 생략 옵션은 별도 작업이다.
- 보안장비의 동작방식·담당팀·부담당자·모니터링 여부는 원문 확인만 가능하다. 이 필드만 바뀐 경우 정규화된 필드별 변경 건수에 포함되지 않는다.
- 새 자산으로 도면을 다시 만들 때 수동 연결/배치를 자동 합치지 않는다. 이전 편집본을 참고해 사용자가 반영해야 한다.
- 전체 교체의 범위는 목록 종류다. 일부 회사/센터만 내려받은 파일에 전체 교체를 사용하면 해당 종류의 다른 범위 항목도 제외될 수 있다. 현재 기본은 추가·갱신이다.
- 네트워크 공통 장비가 업무 미분류로 집계될 수 있다. 공통 장비와 업무 분류 누락의 운영 기준은 회사 규칙에 맞춰 확정해야 한다.
- 회사 담당자를 대상으로 한 작업 시간·성공률 측정은 하지 않았다. 정량 사용성 점수는 부여하지 않는다.

## 회사 인수 우선순위

1. **실제 Excel과 식별 규칙**: 서버/장비/보안/WEB/WAS/DB 각각 실제 또는 비식별 파일로 등록·재등록·변경·부분 목록을 검증한다. 호스트명 변경과 포트/SID 변경의 처리 정책을 확정한다.
2. **공유 운영 경계**: 회사/센터별 원천 범위, 인증/역할, 자산 DB 접근 범위, 감사 사용자, 원본 보관·복구 정책을 확정한다. 현재 loopback 제한을 제거해 단순 공개하지 않는다.
3. **회사 Agent 연결**: 기존 Agent에 읽기 도구를 등록하고 허용 데이터·문서 권한·미확인 응답·실제 인용 정확도를 검증한다.
4. **필요한 경우에만 확장**: 반복 업로드 생략, 보안 필드 구조화, 도면 갱신 비교, Zabbix 사용률 수집은 실제 운영 우선순위에 따라 진행한다.
